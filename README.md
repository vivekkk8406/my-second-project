# Personal Introduction Page

A responsive one-page personal portfolio for **Vivek**, an aspiring software engineer and Computer Science Engineering student. The page presents a short introduction, skills, education, internship experience, strengths, contact details, and a personal photograph.

## Run the project

1. Clone or download this repository.
2. Open the project folder.
3. Open `personnel1.html` in any modern web browser.

No installation, build step, or server is required. For the best development experience, open the folder in VS Code and use a live-preview extension.

## Features implemented

- Responsive layout for desktop and mobile screens
- Personal hero section with name, introduction, and profile photo
- Sections for journey, internship experience, skills, education, and strengths
- Contact area with email, phone number, location, and social-link placeholders
- Skill tags for a clear visual overview of technical interests
- Smooth scrolling for in-page links
- Hover effects on the photograph and social buttons

## Additional features

- Light and dark theme switcher
- The selected theme is saved in the browser with `localStorage`, so it remains selected after refreshing the page
- CSS custom properties make the colors easy to maintain across both themes
- A local profile image (`vivek.jpg`) keeps the page self-contained

## Concepts learned

While completing this project, I practiced:

- Structuring a webpage with semantic HTML sections
- Styling layouts with CSS Flexbox and responsive media queries
- Using CSS variables for reusable theme colors
- Creating visual hierarchy with typography, spacing, cards, and buttons
- Using JavaScript to respond to button clicks
- Using `localStorage` to save a user preference
- Linking HTML, CSS, JavaScript, and local image assets together

## Customization

Update the text, contact information, social links, and `vivek.jpg` image to personalize the page further. Replace placeholder social links with your real LinkedIn and GitHub URLs before publishing.
